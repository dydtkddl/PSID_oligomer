**핵심 결론:** **Phase 1에서는 필수 아님, 하지만 Phase 2 확장과 시각적 임팩트를 위해 계획에 포함 필요**

당신의 PBP-g-PIL 프로젝트에서 전압 인가 시뮬레이션은 과학적 완성도와 전략적 어필 모두를 고려해야 하는 복합적 판단 사항입니다.

## **1. 과학적 근거: 두 가지 접근법의 명확한 구분**

### **평형 MD (EMD): 전도도 정량 예측의 표준**

**원리와 장점:**
평형 상태에서 이온들의 자발적 확산을 관찰하여 전도도를 계산하는 방법입니다. 이는 열역학적으로 가장 엄밀하고 실험과 직접 비교 가능한 접근법입니다.

```python
# 평형 MD에서 전도도 계산 과정
def calculate_equilibrium_conductivity(trajectory, T=300):
    # 1. 이온 확산계수 계산
    D_tfsi = calculate_diffusion_coefficient(trajectory, 'TFSI')

    # 2. Nernst-Einstein 관계식 적용
    e = 1.602e-19  # C
    k_B = 1.381e-23  # J/K
    n_ions = calculate_number_density(trajectory)

    # 3. 이온 전도도 계산
    sigma = (e**2 / (k_B * T)) * n_ions * D_tfsi * 1e-4  # S/cm
    return sigma

# 실험과 직접 비교
exp_sigma = measure_experimental_conductivity()  # AC impedance
sim_sigma = calculate_equilibrium_conductivity(md_trajectory)
relative_error = abs(sim_sigma - exp_sigma) / exp_sigma * 100
```

**왜 이것이 우선인가:**

- 실험에서 측정하는 이온 전도도(AC impedance spectroscopy)는 본질적으로 zero-bias 조건의 전도도입니다
- 선형 응답 이론에 기반한 가장 정확한 방법론입니다
- MACE 포텐셜의 정확도 검증에 최적입니다

### **비평형 MD (NEMD): 메커니즘 시각화와 검증**

**원리와 활용:**
외부 전기장을 가하여 이온의 directed transport를 직접 관찰하는 방법입니다. 정량적 예측보다는 메커니즘 증명과 시각적 임팩트에 특화되어 있습니다.

```bash
# LAMMPS에서 전기장 인가
fix efield tfsi_atoms efield 0.1 0.0 0.0  # x방향 0.1 V/Å

# 주의사항: 현실적 전압과 시뮬레이션 전압의 차이
# 실험: ~1 V/cm = 1e-6 V/Å
# 시뮬레이션: ~0.1 V/Å = 1e6 V/cm (관찰 가능한 수준)
```

**과학적 가치:**

- **호핑 경로 직접 시각화**: TFSI⁻가 π-π stacking column을 따라 이동하는 모습을 동영상으로 제작
- **Anisotropic transport 증명**: 백본 방향 vs 수직 방향 이동성 차이를 명확히 보여줌
- **메커니즘 검증**: "보리굴비 구조" 가설의 시각적 증거 제공

## **3. 전략적 접근: Phase별 단계적 실행**

### **Phase 1 (첫 6개월): 평형 분석 집중**

**과학적 목표:**

- π-π stacking 자발 형성 증명
- TFSI⁻ 호핑 자유에너지 장벽 측정 (PLUMED)
- 실험 전도도와 정량적 비교 (±20% 목표)

**전압 관련 최소한의 작업:**

```python
# Einstein relation으로 전기장 효과 추정
def estimate_field_response(equilibrium_trajectory):
    D_0 = calculate_diffusion_coefficient(equilibrium_trajectory)

    # Nernst-Einstein으로 mobility 계산
    mu = D_0 * e / (k_B * T)  # cm²/V/s

    # 가상의 1 V/μm 전기장에서 drift 속도 추정
    E_typical = 1e-6  # V/Å (현실적 전기장)
    v_drift = mu * E_typical

    return {"mobility": mu, "drift_velocity": v_drift}
```

# 단계적 전기장 증가 실험
E_fields = [0.01, 0.05, 0.1, 0.2]  # V/Å
