## **1. 전략적 접근법: "Digital Twin" 구축 전략**

실제 다공성 시스템의 전체를 모델링하는 대신, 핵심 메커니즘이 발생하는 **기공 표면의 대표적 모델**을 구축합니다. 이는 계산 효율성과 메커니즘 규명의 정확성을 동시에 확보하는 전략입니다.

**핵심 가설:** PBP 기공 내벽에서 자라난 PVBBI⁺ 사슬들이 자발적으로 π-π stacking column을 형성하여 TFSI⁻의 저장벽 호핑 경로를 제공한다는 "보리굴비 구조" 메커니즘을 원자 수준에서 검증합니다.

**시스템 설계 철학:**

- **Target System**: 완전 그라프트된 PBP-g-PVBBI⁺TFSI⁻
- **Control A**: 물리적 혼합 (PBP + 자유 VBBI⁺TFSI⁻)
- **Control B**: 낮은 그라프팅 밀도 (30-50%)
- **Control C**: 다른 음이온 (BF₄⁻, PF₆⁻)

```python
def calculate_van_hove(trajectory, times=[1, 10, 50, 100]):
    """
    호핑 메커니즘의 결정적 증거
    Discrete peaks → Hopping
    Gaussian → Continuous diffusion
    """
    for t_ps in times:
        Gs = compute_self_van_hove(trajectory, t_ps)
        peaks = find_peaks(Gs, prominence=0.01)

        if len(peaks) > 1:
            print(f"t={t_ps}ps: {len(peaks)} peaks → HOPPING mechanism")
        else:
            print(f"t={t_ps}ps: Continuous diffusion")
```

**Anisotropic Diffusion:**

```python
def analyze_anisotropy(trajectory):
    """
    보리굴비 경로 따라 이동하면 D_parallel >> D_perp
    """
    D_parallel = calculate_diffusion_parallel_to_backbone(trajectory)
    D_perp = calculate_diffusion_perpendicular(trajectory)

    anisotropy = D_parallel / D_perp

    if anisotropy > 2.0:
        print(f"Strong anisotropy ({anisotropy:.1f}) → Channeled transport")

    return anisotropy
```

### **호핑 이벤트 자동 검출**

```python
class HoppingAnalysis:
    def detect_hopping_events(self, cutoff=4.5):
        """
        TFSI⁻의 호스트 VBBI⁺ 변화를 추적하여 호핑 이벤트 검출
        """
        events = []
        current_hosts = [None] * len(self.tfsi_atoms)

        for frame in self.trajectory:
            # 각 TFSI⁻의 가장 가까운 VBBI⁺ 찾기
            nearest_vbbi = self.find_nearest_hosts(frame)

            for i, new_host in enumerate(nearest_vbbi):
                if current_hosts[i] is not None and current_hosts[i] != new_host:
                    # 호핑 이벤트 발생!
                    hop_distance = self.calculate_hop_distance(
                        current_hosts[i], new_host
                    )

                    events.append({
                        'time': frame.time,
                        'tfsi_id': i,
                        'from': current_hosts[i],
                        'to': new_host,
                        'distance': hop_distance
                    })

                current_hosts[i] = new_host

        # 통계 분석
        hop_rate = len(events) / self.total_time / len(self.tfsi_atoms)
        avg_hop_distance = np.mean([e['distance'] for e in events])

        return events, hop_rate, avg_hop_distance
```

## **5. 실험 검증 및 비교 분석**

### **이온 전도도 계산**

**Nernst-Einstein 관계식:**

```python
def calculate_conductivity(trajectory, temperature=300):
    """
    σ = (e²/k_B T) * n * q² * D
    """
    # TFSI⁻ 확산 계수
    D_tfsi = calculate_diffusion_coefficient(trajectory)

    # 수밀도
    volume = trajectory.volume
    n_tfsi = len(trajectory.select_atoms('resname TFSI'))
    number_density = n_tfsi / volume

    # 전도도 계산
    e = 1.602e-19  # C
    k_B = 1.381e-23  # J/K

    sigma = (e**2 / (k_B * temperature)) * number_density * D_tfsi

    return sigma * 1e-2  # S/cm
```

**온도 의존성 (Arrhenius 분석):**

```python
def arrhenius_analysis(temperatures, conductivities):
    """
    ln(σ) = ln(σ₀) - E_a/(k_B T)
    """
    x = 1000 / np.array(temperatures)  # 1000/T
    y = np.log(conductivities)

    slope, intercept = np.polyfit(x, y, 1)

    E_a = -slope * 8.617e-5 * 1000  # eV
    sigma_0 = np.exp(intercept)

    print(f"Activation energy: {E_a:.3f} eV")
    print(f"Pre-exponential: {sigma_0:.2e} S/cm")

    return E_a, sigma_0
```
