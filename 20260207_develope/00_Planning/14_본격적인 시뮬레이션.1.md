## **📋 접근 방식 선택: 통합 vs 모듈형**

### **모듈형 접근법 (강력 추천)**

**장점:**

- **안전성:** 중간 단계 실패 시 해당 부분만 재실행
- **유연성:** 필요한 시나리오만 선택적 실행 가능
- **병렬성:** 서로 다른 연구 시나리오 동시 실행
- **디버깅:** 문제 발생 시 특정 스크립트만 수정
- **재사용성:** 평형 구조 하나로 다양한 연구 수행

**실행 전략:**

```bash
# 1단계: 벌크 평형화 (필수, 1회만)
lmp -in 01_bulk_equilibration.lmp

# 2단계: 원하는 연구 시나리오 (병렬 가능)
lmp -in 02_thermal_decomposition.lmp &
lmp -in 03_mechanical_properties.lmp &
```

## **🏗️ 1단계: 벌크 시스템 구축 및 평형화 (필수)**

가장 중요한 기반 작업으로, 단일 분자를 벌크 시스템으로 확장하고 NPT 평형화를 수행합니다.

**파일명:** `01_bulk_equilibration.lmp`

```lammps
# ===================================================================
# BCMBP 벌크 시스템 구축 및 NPT 평형화
# 목표: 단일 분자 → 벌크 시스템 → NPT 평형 구조
# 결과: bcmbp_bulk_equilibrated.data (모든 후속 연구의 기반)
# ===================================================================

# 1. 기본 설정
units           real
atom_style      full
boundary        p p p

print "=========================================="
print "BCMBP 벌크 시스템 구축"
print "단계: 단일분자 → 벌크 → NPT 평형화"
print "=========================================="

# 2. 시스템 구축
read_data       bcmbp.data

# 시스템 크기 설정 (컴퓨터 성능에 따라 조정)
variable        rep_size equal 4    # 4x4x4 = 64개 분자 (1,792 원자)
replicate       ${rep_size} ${rep_size} ${rep_size}

# 원자 겹침 방지
displace_atoms  all random 0.2 0.2 0.2 482749 units box

# 시스템 정보
variable        total_atoms equal atoms
variable        total_mols equal ${total_atoms}/28
print "총 원자 수: ${total_atoms}"
print "총 분자 수: ${total_mols}"

# 3. ReaxFF 설정
pair_style      reaxff NULL safezone 4.0 mincap 300
pair_coeff      * * 11_CHOCl.lammps.ff C H Cl
fix             qeq all qeq/reaxff 1 0.0 10.0 1.0e-6 reaxff

neighbor        2.5 bin
neigh_modify    every 10 delay 0 check yes

# 4. 출력 설정
thermo          1000
thermo_style    custom step temp press vol density pe ke etotal cpu

# 5. 에너지 최소화
print ""
print "=== 에너지 최소화 시작 ==="
minimize        1.0e-4 1.0e-6 2000 20000
write_data      bcmbp_minimized.data
print "=== 에너지 최소화 완료 ==="

# 6. NPT 평형화 (300K, 1 atm)
reset_timestep  0
timestep        0.25

velocity        all create 300.0 987654 dist gaussian

print ""
print "=== NPT 평형화 시작 (300K, 1 atm, 100 ps) ==="
fix             npt_eq all npt temp 300.0 300.0 100.0 iso 1.0 1.0 1000.0

# PBC 문제 해결을 위한 언래핑 좌표 저장
dump            eq all custom 2000 01_equilibration.lammpstrj id type xu yu zu q
dump_modify     eq sort id

run             400000  # 100 ps
print "=== NPT 평형화 완료 ==="

# 7. 결과 저장
variable        final_density equal density
variable        final_temp equal temp
print ""
print "최종 평형 상태:"
print "  온도: ${final_temp} K"
print "  밀도: ${final_density} g/cm³"

undump          eq
unfix           npt_eq

write_data      bcmbp_bulk_equilibrated.data
write_restart   bcmbp_bulk.restart

print ""
print "=========================================="
print "✅ 벌크 평형화 완료!"
print "핵심 출력 파일:"
print "  - bcmbp_bulk_equilibrated.data (후속 연구 입력)"
print "  - 01_equilibration.lammpstrj (평형화 과정)"
print "=========================================="
```

### **시나리오 B: 기계적 물성 측정**

응력-변형률 곡선을 통한 기계적 물성 계산입니다.

**파일명:** `03_mechanical_properties.lmp`

```lammps
# ===================================================================
# 기계적 물성 측정 (인장 실험)
# 목표: 응력-변형률 곡선 및 영률 계산
# 입력: bcmbp_bulk_equilibrated.data
# ===================================================================

units           real
atom_style      full
boundary        p p p

print "=========================================="
print "기계적 물성 측정 (인장 실험)"
print "목표: 응력-변형률 곡선"
print "=========================================="

# 평형 구조 로드
read_data       bcmbp_bulk_equilibrated.data

# ReaxFF 설정
pair_style      reaxff NULL safezone 4.0 mincap 300
pair_coeff      * * 11_CHOCl.lammps.ff C H Cl
fix             qeq all qeq/reaxff 1 0.0 10.0 1.0e-6 reaxff

neighbor        2.5 bin
neigh_modify    every 10 delay 0 check yes

timestep        0.25
reset_timestep  0

# 응력 텐서 출력
thermo          200
thermo_style    custom step temp press pxx pyy pzz lx ly lz vol

# NPT 재평형화
print ""
print "=== NPT 재평형화 ==="
fix             npt_pre all npt temp 300.0 300.0 100.0 iso 1.0 1.0 1000.0
run             20000
unfix           npt_pre

# 변형률 및 응력 변수 정의
variable        L0 equal lx
variable        strain equal "(lx - v_L0)/v_L0"
variable        stress equal "-pxx*0.0001"  # bar → GPa 변환

# 인장 변형 설정
print ""
print "=== 인장 실험 시작 ==="
print "변형률 속도: 0.001/ps (0.1%/ps)"

# x방향 인장, y,z 방향은 자유 수축
fix             nvt_temp all nvt temp 300.0 300.0 100.0
fix             deform all deform 1 x erate 0.001 remap x

# 응력-변형률 데이터 출력
fix             stress_strain all print 200 "${strain} ${stress}" &
                file stress_strain.dat screen no title "# Strain Stress(GPa)"

dump            mech all custom 1000 03_mechanical.lammpstrj id type xu yu zu q
dump_modify     mech sort id

# 15% 변형까지 (37.5 ps)
run             150000

undump          mech
unfix           stress_strain
unfix           deform
unfix           nvt_temp

write_data      bcmbp_deformed.data

print ""
print "=========================================="
print "✅ 기계적 물성 측정 완료!"
print "결과 파일:"
print "  - stress_strain.dat (응력-변형률 데이터)"
print "  - 03_mechanical.lammpstrj (변형 과정)"
print "분석: 초기 기울기 → 영률(Young's modulus)"
print "=========================================="
```

### **시나리오 C: 유리전이온도(Tg) 계산**

온도에 따른 밀도 변화로 유리전이온도를 계산합니다.

**파일명:** `04_glass_transition.lmp`

```lammps
# ===================================================================
# 유리전이온도(Tg) 계산
# 목표: 냉각 과정에서 밀도-온도 관계 분석
# 입력: bcmbp_bulk_equilibrated.data
# ===================================================================

units           real
atom_style      full
boundary        p p p

print "=========================================="
print "유리전이온도(Tg) 계산"
print "방법: 냉각 곡선 밀도 분석"
print "=========================================="

# 평형 구조 로드
read_data       bcmbp_bulk_equilibrated.data

# ReaxFF 설정
pair_style      reaxff NULL safezone 4.0 mincap 300
pair_coeff      * * 11_CHOCl.lammps.ff C H Cl
fix             qeq all qeq/reaxff 1 0.0 10.0 1.0e-6 reaxff

neighbor        2.5 bin
neigh_modify    every 10 delay 0 check yes

timestep        0.25
thermo          1000
thermo_style    custom step temp press vol density pe

# 밀도-온도 데이터 저장
variable        current_temp equal temp
variable        current_density equal density
fix             tg_data all print 1000 "${current_temp} ${current_density}" &
                file density_temperature.dat screen no title "# Temp(K) Density(g/cm3)"

# 1. 고온 용융 (600K)
print ""
print "=== 고온 용융 (600K, 20 ps) ==="
velocity        all create 600.0 987654 dist gaussian
fix             melt all npt temp 600.0 600.0 100.0 iso 1.0 1.0 1000.0
run             80000
unfix           melt

# 2. 단계적 냉각 (600K → 200K)
print ""
print "=== 단계적 냉각 (600K → 200K) ==="

# 냉각 온도 리스트
variable        temp_list index 600 550 500 450 400 350 300 250 200
variable        ntemps equal 9
variable        itemp loop ${ntemps}

label           cooling_loop

    # 현재 온도 설정
    if "${itemp} == 1" then "variable target_temp equal 600"
    if "${itemp} == 2" then "variable target_temp equal 550"
    if "${itemp} == 3" then "variable target_temp equal 500"
    if "${itemp} == 4" then "variable target_temp equal 450"
    if "${itemp} == 5" then "variable target_temp equal 400"
    if "${itemp} == 6" then "variable target_temp equal 350"
    if "${itemp} == 7" then "variable target_temp equal 300"
    if "${itemp} == 8" then "variable target_temp equal 250"
    if "${itemp} == 9" then "variable target_temp equal 200"

    print "냉각 중: ${target_temp} K"

    fix             cool_npt all npt temp ${target_temp} ${target_temp} 100.0 iso 1.0 1.0 1000.0
    run             40000  # 각 온도에서 10 ps
    unfix           cool_npt

    variable        current_rho equal density
    print "  밀도: ${current_rho} g/cm³"

    next            itemp
    jump            SELF cooling_loop

unfix           tg_data
write_data      bcmbp_cooled.data

print ""
print "=========================================="
print "✅ Tg 계산 시뮬레이션 완료!"
print "결과 파일:"
print "  - density_temperature.dat"
print "분석 방법:"
print "  1. 밀도 vs 온도 그래프 작성"
print "  2. 기울기 변화점 → Tg"
print "  3. 일반적으로 두 직선의 교점"
print "=========================================="
```

### **결과 분석 자동화**

```python
#!/usr/bin/env python3
# analyze_bcmbp_results.py - 결과 자동 분석

import numpy as np
import matplotlib.pyplot as plt
from pathlib import Path

def analyze_stress_strain():
    """응력-변형률 곡선 분석"""
    if Path("stress_strain.dat").exists():
        print("📊 응력-변형률 분석")
        data = np.loadtxt("stress_strain.dat")
        strain = data[:, 0]
        stress = data[:, 1]

        # 영률 계산 (초기 기울기)
        linear_region = strain < 0.02  # 2% 이하 선형 구간
        if np.sum(linear_region) > 10:
            young_modulus = np.polyfit(strain[linear_region],
                                     stress[linear_region], 1)[0]
            print(f"  영률: {young_modulus:.2f} GPa")

        # 그래프 저장
        plt.figure(figsize=(10, 6))
        plt.plot(strain * 100, stress, 'b-', linewidth=2)
        plt.xlabel('변형률 (%)')
        plt.ylabel('응력 (GPa)')
        plt.title('BCMBP 응력-변형률 곡선')
        plt.grid(True, alpha=0.3)
        plt.savefig('stress_strain_curve.png', dpi=300, bbox_inches='tight')
        print("  그래프 저장: stress_strain_curve.png")

def analyze_glass_transition():
    """유리전이온도 분석"""
    if Path("density_temperature.dat").exists():
        print("📊 유리전이온도 분석")
        data = np.loadtxt("density_temperature.dat")
        temp = data[:, 0]
        density = data[:, 1]

        # 그래프 저장
        plt.figure(figsize=(10, 6))
        plt.plot(temp, density, 'ro-', linewidth=2, markersize=6)
        plt.xlabel('온도 (K)')
        plt.ylabel('밀도 (g/cm³)')
        plt.title('BCMBP 밀도-온도 관계 (Tg 계산용)')
        plt.grid(True, alpha=0.3)
        plt.savefig('density_temperature.png', dpi=300, bbox_inches='tight')
        print("  그래프 저장: density_temperature.png")
        print("  Tg 계산: 기울기 변화점을 찾아 수동 결정")

if __name__ == "__main__":
    print("=== BCMBP 시뮬레이션 결과 분석 ===\n")

    analyze_stress_strain()
    print()
    analyze_glass_transition()

    print("\n=== 분석 완료 ===")
```
