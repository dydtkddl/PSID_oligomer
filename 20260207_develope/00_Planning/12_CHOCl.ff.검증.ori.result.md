## **즉시 실행: 1단계 기본 검증 테스트**

본격적인 BCMBP 시뮬레이션 전에 **벤질클로라이드 단일 분자 테스트**로 파라미터 작동을 확인하는 것을 강력히 권장합니다.

### **벤질클로라이드 테스트 LAMMPS 스크립트**

```lammps
# 벤질클로라이드 C-Cl 결합 기본 테스트
units real
atom_style charge
boundary p p p

# 시스템 읽기 (벤질클로라이드: ClCH2-C6H5)
read_data benzyl_chloride.data

# ReaxFF 설정 - 검증된 파라미터 사용!
pair_style reaxff NULL safezone 3.0 mincap 150
pair_coeff * * 11_CHOCl.ff C H O Cl

# 원자 질량 설정 (순서 중요: C H O Cl)
mass 1 12.0000  # C
mass 2 1.0080   # H
mass 3 15.9990  # O
mass 4 35.4500  # Cl

# 전하 평형 (필수)
fix qeq all qeq/reaxff 1 0.0 10.0 1.0e-6 reaxff

# 에너지 최소화
minimize 1.0e-4 1.0e-6 1000 10000

# 300K 안정성 테스트
timestep 0.25
velocity all create 300.0 12345
fix nvt1 all nvt temp 300.0 300.0 100.0

thermo 100
thermo_style custom step temp pe etotal press

dump 1 all custom 100 benzyl_300K.lammpstrj id type x y z q
run 2000  # 0.5 ps

unfix nvt1

# 고온 테스트 (1000K에서 C-Cl 결합 안정성)
fix nvt2 all nvt temp 1000.0 1000.0 100.0
dump 2 all custom 100 benzyl_1000K.lammpstrj id type x y z q
run 10000  # 2.5 ps

write_data final_benzyl.data
```

**기대 결과:**

- 300K: 구조 안정 유지
- 1000K: C-Cl 결합 활성화되지만 완전 파괴되지 않음
- 방향족 고리: 두 온도 모두에서 보존

### **시뮬레이션 설계**

```python
# BCMBP 파일럿 시뮬레이션 설정
simulation_config = {
    # 시스템 구성
    'n_bcmbp_molecules': 10,        # 작게 시작
    'box_density': 0.8,             # g/cm³
    'force_field': '11_CHOCl.ff',

    # 온도 프로파일 (가속화 전략)
    'temperature_schedule': [
        (300, 50),     # 평형화: 300K, 50ps
        (600, 100),    # 초기 활성화: 600K, 100ps
        (1000, 200),   # 주반응: 1000K, 200ps
        (1200, 150),   # 완전 가교: 1200K, 150ps
        (300, 100)     # 냉각 및 안정화: 300K, 100ps
    ],

    # HCl 제거 프로토콜 (중요!)
    'hcl_removal': {
        'check_interval': 50,        # ps마다 확인
        'pressure_threshold': 5.0,   # atm
        'removal_fraction': 0.3,     # 30%씩 점진적 제거
        'equilibration_time': 20     # 제거 후 재평형화
    }
}
```
