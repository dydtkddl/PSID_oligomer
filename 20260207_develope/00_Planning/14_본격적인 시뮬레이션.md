테스트가 성공했다니 정말 좋습니다! 기본적인 ReaxFF 설정과 CHOCl 포스필드 호환성이 완벽히 검증되었으므로, 이제 **실제 연구에 활용할 수 있는 고급 시뮬레이션**으로 확장할 준비가 완료되었습니다.

## **🔍 먼저 확인해야 할 중요 사항**

현재 성공한 스크립트에서 다음 설정이 올바른지 한 번만 확인해주세요:

```lammps
pair_coeff * * 11_CHOCl.lammps.ff C H Cl    # O 제외, 3개 원소만 (중요!)
```

BCMBP 시스템은 C, H, Cl 3개 타입만 있으므로 위와 같이 설정되어 있어야 합니다. 만약 여전히 `C H O Cl` (4개)로 되어 있다면 반드시 수정하세요.

## **📈 단계별 확장 로드맵**

### **1단계: 시스템 스케일 확장 (단일분자 → 벌크)**

현재 28개 원자 단일 분자로는 실제 물성(밀도, 열전도도 등)을 계산할 수 없습니다. 먼저 **벌크 시스템**을 만들어야 합니다.

**간단한 확장 방법:**

```lammps
read_data       bcmbp.data
replicate       4 4 4           # 4×4×4 = 64개 분자 (1,792 원자)
# 또는 더 큰 시스템: replicate 5 5 5 (125개 분자, 3,500 원자)
```

### **2단계: 앙상블 확장 (NVT → NPT)**

실제 물성을 얻으려면 **압력 제어(NPT)**가 필수입니다. 이를 통해 적절한 밀도와 구조를 얻을 수 있습니다.

### **3단계: 연구 목적별 시뮬레이션**

벌크 시스템이 준비되면 다양한 연구 시나리오를 적용할 수 있습니다.

## **🎯 즉시 실행 가능한 벌크 시스템 스크립트**

다음은 BCMBP 벌크 시스템 생성 및 NPT 평형화 스크립트입니다:

```lammps
# ===================================================================
# BCMBP Bulk System - NPT Equilibration
# 목표: 실제 물성 계산 가능한 벌크 시스템 구축
# ===================================================================

units           real
atom_style      full
boundary        p p p

# 1. 시스템 확장
read_data       bcmbp.data
replicate       4 4 4           # 64개 분자 (1,792 원자)

# 초기 구조 약간 무작위화 (충돌 방지)
displace_atoms  all random 0.3 0.3 0.3 12345 units box

# 2. ReaxFF 설정 (메모리 증가)
pair_style      reaxff NULL safezone 4.0 mincap 300
pair_coeff      * * 11_CHOCl.lammps.ff C H Cl
fix             qeq all qeq/reaxff 1 0.0 10.0 1.0e-6 reaxff

neighbor        2.5 bin
neigh_modify    every 10 delay 0 check yes

# 3. 출력 설정 (밀도 포함)
thermo          200
thermo_style    custom step temp press vol density pe ke etotal

print "=========================================="
print "BCMBP 벌크 시스템 NPT 평형화"
print "시스템: 64개 분자 (1,792 원자)"
print "목표: 300K, 1 atm에서 평형 밀도 계산"
print "=========================================="

# 4. 에너지 최소화
print "=== 에너지 최소화 ==="
minimize        1.0e-4 1.0e-6 2000 20000

# 5. 초기 속도 및 온도 설정
reset_timestep  0
timestep        0.25
velocity        all create 300.0 482749 dist gaussian

# 6. NPT 평형화 (300K, 1 atm)
print "=== NPT 평형화 시작 (300K, 1 atm, 50 ps) ==="
fix             npt1 all npt temp 300.0 300.0 100.0 iso 1.0 1.0 1000.0

# PBC 문제 해결을 위한 언래핑 좌표 저장
dump            1 all custom 1000 bcmbp_bulk_npt.lammpstrj id type xu yu zu q
dump_modify     1 sort id

run             200000  # 50 ps
print "=== NPT 평형화 완료 ==="

undump          1
unfix           npt1

# 7. 최종 구조 저장
write_data      bcmbp_bulk_equilibrated.data

print "=========================================="
print "✅ 벌크 시스템 평형화 완료!"
print "최종 밀도 확인 필요 (실험값과 비교)"
print "출력 파일:"
print "  - bcmbp_bulk_npt.lammpstrj (궤적)"
print "  - bcmbp_bulk_equilibrated.data (평형 구조)"
print "=========================================="
```

run             20000  # 각 온도에서 5 ps

variable        T equal $T-50
jump            SELF cooling_loop

print "=== 유리전이온도 계산 완료 ==="

## **📊 결과 분석 자동화 스크립트**

#!/usr/bin/env python3
# analyze_bcmbp_results.py - BCMBP 시뮬레이션 결과 종합 분석

import numpy as np
import matplotlib.pyplot as plt
from pathlib import Path

def analyze_density_evolution(logfile='log.lammps'):
    """NPT 시뮬레이션에서 밀도 수렴 분석"""
    print("📊 밀도 수렴 분석")

    data = []
    with open(logfile, 'r') as f:
        capture = False
        for line in f:
            if 'Step' in line and 'Density' in line:
                capture = True
                continue
            if capture and line.strip():
                try:
                    values = [float(x) for x in line.split()]
                    data.append(values)
                except:
                    capture = False

    if data:
        data = np.array(data)
        steps = data[:, 0]
        density = data[:, 4]  # density 열 위치 확인 필요

        plt.figure(figsize=(10, 6))
        plt.plot(steps, density)
        plt.xlabel('Step')
        plt.ylabel('Density (g/cm³)')
        plt.title('Density Evolution during NPT Equilibration')
        plt.grid(True)
        plt.savefig('density_evolution.png', dpi=300)

        final_density = np.mean(density[-1000:])  # 마지막 1000 포인트 평균
        print(f"  최종 평형 밀도: {final_density:.3f} g/cm³")
        print(f"  그래프 저장: density_evolution.png")

### **모듈형 접근법 (강력 추천)**

- **안전성:** 중간 단계 실패 시 해당 부분만 재실행

# ===================================================================
# 기계적 물성 측정 (인장 실험)
# 목표: 응력-변형률 곡선 및 영률 계산

### **시나리오 C: 유리전이온도(Tg) 계산**

온도에 따른 밀도 변화로 유리전이온도를 계산합니다.

**파일명:** `04_glass_transition.lmp`

```lammps
# ===================================================================
# 유리전이온도(Tg) 계산
# 목표: 냉각 과정에서 밀도-온도 관계 분석
# 입력: bcmbp_bulk_equilibrated.data
# ===================================================================

units           real
atom_style      full
boundary        p p p

print "=========================================="
print "유리전이온도(Tg) 계산"
print "방법: 냉각 곡선 밀도 분석"
print "=========================================="

# 평형 구조 로드
read_data       bcmbp_bulk_equilibrated.data

# ReaxFF 설정
pair_style      reaxff NULL safezone 4.0 mincap 300
pair_coeff      * * 11_CHOCl.lammps.ff C H Cl
fix             qeq all qeq/reaxff 1 0.0 10.0 1.0e-6 reaxff

neighbor        2.5 bin
neigh_modify    every 10 delay 0 check yes

timestep        0.25
thermo          1000
thermo_style    custom step temp press vol density pe

# 밀도-온도 데이터 저장
variable        current_temp equal temp
variable        current_density equal density
fix             tg_data all print 1000 "${current_temp} ${current_density}" &
                file density_temperature.dat screen no title "# Temp(K) Density(g/cm3)"

# 1. 고온 용융 (600K)
print ""
print "=== 고온 용융 (600K, 20 ps) ==="
velocity        all create 600.0 987654 dist gaussian
fix             melt all npt temp 600.0 600.0 100.0 iso 1.0 1.0 1000.0
run             80000
unfix           melt

# 2. 단계적 냉각 (600K → 200K)
print ""
print "=== 단계적 냉각 (600K → 200K) ==="

# 냉각 온도 리스트
variable        temp_list index 600 550 500 450 400 350 300 250 200
variable        ntemps equal 9
variable        itemp loop ${ntemps}

label           cooling_loop

    # 현재 온도 설정
    if "${itemp} == 1" then "variable target_temp equal 600"
    if "${itemp} == 2" then "variable target_temp equal 550"
    if "${itemp} == 3" then "variable target_temp equal 500"
    if "${itemp} == 4" then "variable target_temp equal 450"
    if "${itemp} == 5" then "variable target_temp equal 400"
    if "${itemp} == 6" then "variable target_temp equal 350"
    if "${itemp} == 7" then "variable target_temp equal 300"
    if "${itemp} == 8" then "variable target_temp equal 250"
    if "${itemp} == 9" then "variable target_temp equal 200"

    print "냉각 중: ${target_temp} K"

    fix             cool_npt all npt temp ${target_temp} ${target_temp} 100.0 iso 1.0 1.0 1000.0
    run             40000  # 각 온도에서 10 ps
    unfix           cool_npt

    variable        current_rho equal density
    print "  밀도: ${current_rho} g/cm³"

    next            itemp
    jump            SELF cooling_loop

unfix           tg_data
write_data      bcmbp_cooled.data

print ""
print "=========================================="
print "✅ Tg 계산 시뮬레이션 완료!"
print "결과 파일:"
print "  - density_temperature.dat"
print "분석 방법:"
print "  1. 밀도 vs 온도 그래프 작성"
print "  2. 기울기 변화점 → Tg"
print "  3. 일반적으로 두 직선의 교점"
print "=========================================="
```

### **결과 분석 자동화**

```python
#!/usr/bin/env python3
# analyze_bcmbp_results.py - 결과 자동 분석

import numpy as np
import matplotlib.pyplot as plt
from pathlib import Path

def analyze_stress_strain():
    """응력-변형률 곡선 분석"""
    if Path("stress_strain.dat").exists():
        print("📊 응력-변형률 분석")
        data = np.loadtxt("stress_strain.dat")
        strain = data[:, 0]
        stress = data[:, 1]

        # 영률 계산 (초기 기울기)
        linear_region = strain < 0.02  # 2% 이하 선형 구간
        if np.sum(linear_region) > 10:
            young_modulus = np.polyfit(strain[linear_region],
                                     stress[linear_region], 1)[0]
            print(f"  영률: {young_modulus:.2f} GPa")

        # 그래프 저장
        plt.figure(figsize=(10, 6))
        plt.plot(strain * 100, stress, 'b-', linewidth=2)
        plt.xlabel('변형률 (%)')
        plt.ylabel('응력 (GPa)')
        plt.title('BCMBP 응력-변형률 곡선')
        plt.grid(True, alpha=0.3)
        plt.savefig('stress_strain_curve.png', dpi=300, bbox_inches='tight')
        print("  그래프 저장: stress_strain_curve.png")

def analyze_glass_transition():
    """유리전이온도 분석"""
    if Path("density_temperature.dat").exists():
        print("📊 유리전이온도 분석")
        data = np.loadtxt("density_temperature.dat")
        temp = data[:, 0]
        density = data[:, 1]

        # 그래프 저장
        plt.figure(figsize=(10, 6))
        plt.plot(temp, density, 'ro-', linewidth=2, markersize=6)
        plt.xlabel('온도 (K)')
        plt.ylabel('밀도 (g/cm³)')
        plt.title('BCMBP 밀도-온도 관계 (Tg 계산용)')
        plt.grid(True, alpha=0.3)
        plt.savefig('density_temperature.png', dpi=300, bbox_inches='tight')
        print("  그래프 저장: density_temperature.png")
        print("  Tg 계산: 기울기 변화점을 찾아 수동 결정")

if __name__ == "__main__":
    print("=== BCMBP 시뮬레이션 결과 분석 ===\n")

    analyze_stress_strain()
    print()
    analyze_glass_transition()

    print("\n=== 분석 완료 ===")
```
